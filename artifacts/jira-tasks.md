| Поле | Значение |
|---|---|

| **Jira Key** | KAN-7 |
| **Summary** | Загрузка настроек конфигуратора раскроя при переходе в категорию |
| **Priority** | High |
| **Dependencies** | — |

**Description:**
При переходе в категорию необходимо загрузить настройки конфигуратора раскроя сэндвич-панелей, содержащие допустимые минимальные значения ширины и длины.

4. Настройки используются для валидации в форме раскроя

## Задача T-02

| Поле | Значение |
|---|---|
| **Local ID** | T-02 |
| **Jira Key** | KAN-8 |
| **Summary** | Форма ввода параметров раскроя с автоматическим расчетом площади и стоимости |
| **Priority** | High |
| **Dependencies** | T-01 |

**Description:**
Реализация формы конфигуратора раскроя сэндвич-панелей с автоматическим расчетом. Форма должна содержать:
- Выбор продукта из списка (продукт имеет размеры length, width)
- Поля ввода: ширина, длина, количество, маркировка
- Автоматический расчет площади: площадь = ширина × длина
- Автоматический расчет стоимости: стоимость = площадь × cost_one_rub

**Source Requirements:** FR-01, FR-02, FR-03, FR-04

**Acceptance Criteria:**
1. Пользователь может выбрать продукт из выпадающего списка
2. Доступны поля ввода для ширины, длины, количества и маркировки
3. Площадь рассчитывается автоматически при изменении ширины или длины
4. Стоимость отображается на основании рассчитанной площади и cost_one_rub

## Задача T-03

| Поле | Значение |
|---|---|
| **Local ID** | T-03 |
| **Jira Key** | KAN-9 |
| **Summary** | Валидация размеров раскроя на фронте и на бэке с проверкой размещения на листе |
| **Priority** | High |
| **Dependencies** | T-01 |

**Description:**
Реализация валидации введенных размеров раскроя на фронтенде и бэкенде. Изделие должно помещаться на лист с учетом возможности поворота при раскрое.

**Source Requirements:** FR-06, VR-01, VR-02, VR-03

**Acceptance Criteria:**
1. Валидация минимальных значений: ширина >= min_width, длина >= min_length
2. Валидация размещения на листе с учетом поворота изделия
3. Валидация выполняется на фронте (before submit)
4. Валидация выполняется на бэке (при получении запроса)
5. При ошибке валидации отображается понятное сообщение пользователю

| Поле | Значение |
|---|---|
| **Local ID** | T-04 |
| **Jira Key** | KAN-10 |
| **Summary** | Добавление сконфигурированного продукта в корзину |
| **Priority** | High |
| **Dependencies** | T-02, T-03 |

**Description:**
Реализация функциональности добавления сконфигурированного продукта в корзину с сохранением всех введенных параметров.

**Source Requirements:** FR-05, BR-05

**Acceptance Criteria:**
1. При добавлении в корзину отправляется запрос с телом:
```json
{
  "configurator": "sandwich_m2",
  "product_id": "<id>",
  "product_category_id": "<id>",
  "quantity": "<кол-во>",
  "width": "<ширина>",
  "length": "<длина>"
}
```
2. Все введенные параметры сохраняются
3. После успешного добавления пользователь получает подтверждение
