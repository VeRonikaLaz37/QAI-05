## 1. Scope

Внедрение конфигуратора раскроя сэндвич-панелей с автоматическим расчетом площади и стоимости за м², включая валидацию размеров и интеграцию с корзиной.

## 2. Requirements

| ID | Требование |
|---|---|
| FR-01 | Выбор продукта из списка (продукт имеет размеры length, width) |
| FR-02 | Ввод ширины, длины, количества и маркировки |
| FR-03 | Автоматический расчет площади: площадь = ширина × длина |
| FR-04 | Автоматический расчет стоимости: стоимость = площадь × cost_one_rub |
| FR-05 | Сохранение параметров при добавлении в корзину |
| FR-06 | Валидация размеров на фронте и на бэке (изделие должно помещаться на лист с учетом поворота) |
| FR-07 | Получение настроек конфигуратора при переходе в категорию (min_length=100, min_width=100) |

## 3. Business Rules

| ID | Правило |
|---|---|
| BR-01 | Площадь = ширина × длина |
| BR-02 | Стоимость = площадь × cost_one_rub |
| BR-03 | Валидация: изделие должно помещаться на лист с учетом возможности поворота при раскрое |
| BR-04 | Минимальные допустимые значения: min_length=100, min_width=100 |
| BR-05 | Тело запроса при добавлении в корзину: `{configurator, product_id, product_category_id, quantity, width, length}` |

## 4. Acceptance Criteria

| ID | Критерий |
|---|---|
| AC-01 | Пользователь может выбрать продукт из списка |
| AC-02 | Пользователь может ввести ширину, длину, количество и маркировку |
| AC-03 | Площадь автоматически рассчитывается как ширина × длина |
| AC-04 | Стоимость автоматически рассчитывается как площадь × cost_one_rub |
| AC-05 | При добавлении в корзину все введенные параметры сохраняются |
| AC-06 | Валидация проверяет, что изделие помещается на лист с учетом поворота |
| AC-07 | При переходе в категорию загружаются настройки конфигуратора с минимальными значениями |

## 5. Validation Rules

| ID | Правило |
|---|---|
| VR-01 | Ширина и длина >= min_width и min_length |
| VR-02 | Изделие должно помещаться на лист с учетом поворота |
| VR-03 | Валидация дублируется на фронте и на бэке |

## 6. Dependencies

- API настроек конфигуратора (min_length, min_width)
- API каталога продуктов
- API корзины

## 7. Ambiguities

| ID | Неоднозначность |
|---|---|
| AMB-01 | Размеры листа для валидации не указаны |
| AMB-02 | Единицы измерения ширины/длины не определены |
| AMB-03 | Логика поворота при раскрое не описана (90°? другой угол?) |
| AMB-04 | Поле "маркировка" не раскрыто |

## 8. Missing Information

- Размеры листа (или原材料) для валидации
- Единицы измерения
- Алгоритм проверки поворота
- Формат/назначение маркировки

## 9. Conflicts

Не обнаружены.

## 10. Positive Flows

| ID | Сценарий |
|---|---|
| PF-01 | Выбор продукта → Ввод размеров → Расчет → Добавление в корзину |
| PF-02 | Корректная валидация → Сохранение данных |

## 11. Negative Flows

| ID | Сценарий |
|---|---|
| NF-01 | Размеры < minimum → Ошибка валидации |
| NF-02 | Изделие не помещается на лист → Ошибка валидации |
| NF-03 | Пустые обязательные поля → Ошибка валидации |

## 12. Boundaries

- Минимум: 100 для ширины и длины
- Граничные: ровно 100, < 100, максимальные значения
